# Source Registry

> Index of every immutable source consumed by this wiki. Sources live in
> `docs/` (papers, call notes, questionnaires) or are pipeline outputs.
> Each source gets a stable ID (`S1`, `S2`, …) used in evidence tags.

## Format

```
S<N>: <citation or filename> -- C1: <claim>, C2: <claim>, ...
       path: <relative path to source>
       summary page: <relative path to sources/*.md if one exists>
       ingested: YYYY-MM-DD
```
